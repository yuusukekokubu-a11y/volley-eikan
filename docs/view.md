# 試合の画面（試作）

試合（3セットマッチ・5セットマッチ、試作）。試合の計算（`src/sim/game.ts` の Match と、`match.ts` の SetGame）で1ラリーずつ進め、記録を簡易3D（Three.js）で再生する。

- 試合の前とセットの間：仮の画面で先発メンバーと並び・方針を変える（自チームだけ。初期値は前のセットの先発と並び）
  - 試合の前だけ：3セットマッチ／5セットマッチを選ぶ
  - 並びの図（ゾーン4・3・2／5・6・1）とリベロ：2か所を続けて押すと入れ替え。控えを押してから位置（またはリベロ）を押すと先発と入れ替え。「並びを回す」で全体を1つ回す
  - 方針：攻撃・ブロック・レシーブ
  - その下に、停止画面と同じ選手の一覧
  - セットの間は、セット数と各セットの得点も出す。疲れている選手には「疲れ」と出す
  - セットの始まりの停止（試合開始）は、この画面と同じ役目なので出さない
- セットの中で止まる場面（10点・20点、連続失点。最終セットは8点）では、仮の停止画面を出す
  - 左：スコア、止まった理由、セット数、タイムアウトと交代の回数、ローテーションの図
  - 右：コート上の選手・リベロ・控えの一覧（1人2行。背番号、ポジション、学年、身長、6能力を「B 72」のように段階と数値で、調子／適性の記号（－△○◎）、特能、疲れていれば「足が止まってきた」）
  - 下：タイムアウト（監督特能を1つ選ぶ → 方針を変える）／選手交代（下がる選手 → 入る選手。できない組み合わせは出さない）／試合に戻る／見せ方の切り替え
- コートチェンジ：毎セットの終わりと最終セットの8点で、選手とボールをコートの中心で180度回して見せる（記録の座標はそのまま）。8点のコートチェンジは、そのラリーの再生が終わってから見せる
- 能力の段階：S 90〜／A 80〜／B 70〜／C 60〜／D 50〜／E 40〜／F 20〜／G 〜19（`common.ts` の ABILITY_RANKS）
- 試合の終わり：勝ったチームと各セットの得点。「新しい試合」で試合前に戻る
- 見せ方：フル（全ラリーを再生）と、結果のみ（止まる場面まで一気に進む）。ハイライトは「試合前画面・停止画面」の段階で
- 相手（青）は交代だけをする。相手の交代・ピンチサーバー、ピンチサーバーが戻ったことは、得点の一言の後ろと次の停止画面に出す
- 交代で「サーブの間だけ（ピンチサーバー）」を選べる（次にサーブする時の、次のサーバーだけ）
- 監督特能：試合前の画面で試作用に3つまで選ぶ（獲得・失効は育成の段階で）。停止画面に持っている監督特能と、いま効いているもの（残りラリー数、エース対策の相手）を出す。勝負勘を持っていて未使用なら「勝負勘」のボタン（次の1ラリーだけ方針を変える）。データ分析を持っていれば、試合前・セット間の画面に「相手の傾向」を出す

- 起動：`npm run dev` → 表示された URL をブラウザで開く（横持ち 844×390 が基準）
- 公開：main に push すると GitHub Pages（https://yuusukekokubu-a11y.github.io/volley-eikan/）に自動で反映される
- 操作（すべてタップ）：再生／一時停止、速度（1・2・4倍）、見せ方（フル／結果のみ）、男子／女子
- URL の指定：`?seed=7`（試合の種）、`&sets=5`（5セットマッチ）、`&gender=female`、`&mode=result`（結果のみ）

## 動きの確認用の画面（inspect.html）

ゲームの機能ではなく、動きを確かめるための画面。公開先は https://yuusukekokubu-a11y.github.io/volley-eikan/inspect.html

- 下の列で選手を選ぶと、カメラがその選手を追いかける（もう一度押すと中継の角度に戻る）。角度は横から／後ろから／前から
- ほかの選手は薄く表示（「全員表示」に切り替え可）
- 再生の速さは現実の0.1・0.25・0.5・1倍。一時停止、1コマ（1/30秒）・0.1秒の進める／戻す、つまみで好きな時刻へ
- 上の列で見たい動作（スパイク・ジャンプサーブ・ブロック・レシーブ・飛びつき・トス）を選ぶと、その動作がある場面を探し、その選手を追いかけて少し前から再生する。同じボタンをもう一度押すと次の場面
- URL の指定：`?action=spike`、`seed=4`、`player=A2`、`view=back`、`t=3.5`、`play=0`
- 特能：「特能」ボタンで一覧を開き、1つ選ぶと赤チームの、その特能が効く位置の選手に持たせる（`?trait=killBlock` でも指定できる）
- 解禁型の動作（バックアタック・ツーアタック・リバウンド・ブロード）：上の「見たい動作」のボタンで探せる。押すと赤チームにその特能を持たせてから探す
- ブロードの片足踏み切り：踏み切る脚で踏み込み、反対の脚は膝を高く引き上げる（`pose.ts`）。ツーアタックは、トスの構えから手前の手だけを伸ばして押し込む


## 作り

- `src/view/playback.ts`：記録から、ある時刻の状態（位置・移動の速さ・ジャンプの段階・動作のポーズ、ボール）を求める。計算はしない
- `src/view/pose.ts`：状態から関節の角度を決める（Three.js とは切り離してある）
- `src/view/motion.ts`：人形の動き（関節をなめらかにつなぐ・体の向き・上体の傾き・待機中の揺れ）
- `src/view/figureB.ts`：人形の見た目（デフォルメ体型）。部品は `figure.ts`
- `src/view/render3d.ts`：Three.js。テレビ中継のように遠くから少し望遠で見る角度。関節の角度は目標へなめらかに寄せる

## 人形の見た目

手足が浮いたデフォルメ体型に決定（肘付きの人形と見比べて選んだ）。

- 腕と脚はなく、手と靴が体から浮いている。頭は大きめ、体は丸い。顔は点の目だけのオリジナル
- 手と靴は見えない腕・脚（pose.ts の関節の角度）の先に置く。触る瞬間は手を触る点へ直接置く
- しゃがむと体が沈み、ジャンプでは空中で靴を引き寄せる。身長差は人形全体の大きさで見せる
- 待っている間（助走開始位置でパスとトスを見る時など）は、小さく足踏みして体を左右に揺らし、棒立ちに見えないようにする
- サーブトスは片手で放り上げ、ジャンプ系のサーブはスパイクと同じ腕振りで打つ
- 脚と腕がない分、動きを大げさに見せる（`figureB.ts` の `EXAG`）：沈み込みは2.2倍、靴の前後の振り1.7倍・持ち上げ1.8倍、走る時は一歩ごとに体が弾み、後ろへ引いた手は大きく見せる

## 人形の動き

- 動きは見えない脚・腕の関節の角度（太もも・すね・膝、腕・肘）で決め、靴と手をその先に置く。床では「低い方の足が床に着く」ように腰の高さを決め、空中では脚をたたんでも腰の高さを保つ
- 脚と上体のポーズ：待機（軽く膝を曲げ、わずかに重心を揺らす）、レシーブの構え（深く腰を落とす）、移動（脚を交互に振る。速いほど歩幅が大きい）、踏み込み → ジャンプ → 空中（脚をたたむ）→ 着地（膝で沈む）、飛びつき（走った勢いのまま倒れ込む）
- 順番は「移動 → 着いてから動作のポーズ」。構え始めは、その動作に向けた移動が終わった時刻より前にしない（記録で先に着いている時はそこから構える）
- 体の向き：動作の時は動作の方向（トス・スパイク・サーブは打つ方向、受けるボールには来る方へ少し横を向く、ブロックはネットの向こう）。それ以外は速く走る時は進む方向、ゆっくりの時はボールの方
- 上体：加速で前傾、減速で後ろに重心、横への加速で内側へ傾く。上体と頭はボールを目で追う
- 触る瞬間（レシーブ・トス・スパイク・ブロック・サーブ）：手をボールの表面に置く

## 再生の速さ

現実の速さより少しゆっくり見せる。「1倍」は現実の速さ×`PLAYBACK_RATE`（`src/view/common.ts`、今は0.8）で、2倍・4倍もこれが基準。試合の計算と記録の時刻は変えず、描画の時間の進め方だけを変える。

## 移動の速さの付け方（描画側）

移動の始まり・終わりの時刻と位置は記録どおり。途中の速さだけを変える。

- 普通の移動：ゆっくり動き出して加速し、止まる前に減速する
- スパイクの助走（踏み切りの時刻に着く移動。時刻と長さは計算で決まる）：踏み込むほど速くなり、後半で腕を後ろへ大きく引く。最後の踏み込みで沈んでから跳び、踏み切りで腕を振り上げる
- 飛びつきの走り込み（飛びつきの時刻まで続く移動）：加速したまま倒れ込む
