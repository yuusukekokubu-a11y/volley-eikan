# 描画の比較ページ（試作）

試合計算の記録（RallyRecord）を、2D（擬似的な奥行き）と簡易3D（Three.js）の両方で再生して見比べるためのページ。

- 起動：`npm run dev` → 表示された URL をブラウザで開く（横持ち 844×390 が基準）
- 操作（すべてタップ）：再生／一時停止、速度（1・2・4倍）、次へ（次のラリー）、表示（並べる → 2Dだけ → 3Dだけ）、男子／女子
- URL の指定：`?seed=7`（最初のラリーの種）、`&mode=2d`／`3d`／`split`、`&gender=female`、`&t=3.9`（その時刻で止める。見た目の確認用）
- ラリーが終わると自動で次へ進む。得点した側がサーブ、サイドアウトでローテーションを回すところまでは入れてある（セットの区切り・停止・交代は次の段階）

## 作り

- `src/view/playback.ts`：記録から、ある時刻の状態（選手の位置・ジャンプの高さ・ポーズ、ボール）を求める。2D・3D共通。計算はしない
- `src/view/render2d.ts`：Canvas 2D。奥ほど少し小さく・上へ、少し右へずらす簡単な投影
- `src/view/render3d.ts`：Three.js。テレビ中継のように遠くから少し望遠で見る角度
- 選手は両方とも「カプセルの体＋頭＋腕2本」。ポーズはスパイクの腕振り・ブロックの両腕上げ・トスの両手・レシーブのかがみ
- ボールは本体と床の影を別に描く（高さとコースの両方が分かるように）
- 画面の端に「〇〇のスパイク」程度の一言、左上に打点とブロック到達点を出す（比較用の表示）
