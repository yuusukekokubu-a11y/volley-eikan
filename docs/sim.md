# 試合計算（1ラリー）メモ

`src/sim/` が試合の計算。描画は知らない。`simulateRally(input)` が1ラリーの記録 `RallyRecord` を返す。

- 型：`src/sim/types.ts`
- 調整用の数値：`src/sim/constants.ts`（試作で変える前提の値はすべてここ）
- 特能の受け皿：`src/sim/traits.ts`（今はサーブの解禁型2つだけ登録）
- 確認用：`npm run rally`（多数のラリーの集計）、`npm run rally -- 19`（種19のラリーの中身）、`npm run tactics`（能力が偏ったチームでの作戦の比較）

## 記録の形

- 座標はメートル。x は長辺方向でネットが x=0、チームAは x<0、Bは x>0。y は短辺方向、z は高さ
- `placements`：ラリー開始時の選手の位置
- `events`：時刻順。`move`（移動）、`jump`（跳ぶ）、`action`（サーブ・レシーブ・トス・スパイクなどの動作）、`land`（ボールが床に落ちた）、`point`（得点）
- `ball`：ボールの軌道の区間の列。水平は等速、高さは `z0 + (z1-z0)s + 4·bulge·s(1-s)`
- スパイクの `action` には打点（cm）、ブロックの到達点（cm）、ブロッカー、ブロックの上から打ち抜いたか、が入る
- レシーブ・ディグの `action` には「位置のずれ（m）」と「回転・勢い（0〜1）」が入る
- `load`：選手ごとの負荷（跳んだ回数・動いた距離など）。疲れへの換算は試合側（次の段階）で行う

## 仕様にない部分で決めたこと（現実のバレーに合わせた）

- 能力：身長は cm、ほかは 1〜100（特能などの上乗せで100を超えることはある）。ポジション適性は4段階（下の「選手のデータ」）
- 打点＝身長×1.33（指高）＋跳躍から決まる跳び上がり（45〜100cm）。ブロックの到達点は跳び上がりの78%
- ネットの高さ：高校男子2.40m、高校女子2.20m
- 並びは 5-1 を想定。リベロは後衛のミドルと自動で入れ替わる（サーブを打つミドルは除く）
- サーブレシーブはリベロとアウトサイドを中心に3人。セッターは受けない
- トスの種類：速攻・時間差・平行・オープン。ずれが小さい時だけ速いトスを使える。セッターが1本目を触った時や、ずれが大きい時は、ほかの選手が二段トス（オープンのみ）
- 打てないトスはつなぎで返す（相手のチャンスボール）。ずれが大きすぎるレシーブは相手コートへ返ってしまうことがある
- スパイクの結果：ミス（ネット・アウト）／フェイント・軟打／ブロックのシャット・ブロックアウト・ワンタッチ／抜けた強打
- ブロックは「反応→横移動→踏み切り」がトスの滞空時間に間に合うかで枚数と間に合い具合が決まる。時間差ではミドルがフェイクに跳ぶことがある
- 守備は「ボールが来るまでに走れる距離＋飛びつき」で届くかを判定。跳んだ選手は着地してすぐは動けない
- シャットされたボールを味方が拾う（フォロー）ことがある
- 打ち分け：テクニックが高いほど守備のいない所を選べ、狙いのずれも小さい。低い打点だとネットを越えるために深くしか打てない
- 男女の重み：体の能力（跳躍・パワー・スピード）が攻撃力・サーブの威力に効く量に「体の重み」、テクニックに「技の重み」、作戦が合った時の補正に「作戦の重み」を掛ける。ブロック能力（読みとタイミング）と、移動の速さそのものには掛けない
- サーブ：フローターは誰でも打てる。ジャンフロ・スパイクサーブは解禁特能が必要（両方あればスパイクサーブ）
- ダイレクト：相手の返球がネットから1.5m以内に来たら、届く前衛が直接打つ（基本の動作）。場面 `direct` で特能が効く

## 記録の書き方（結果には影響しない）

- レシーブ・ディグ・フォローの移動先は「体の立ち位置」。触る点（動作の位置）から、ボールが進んでくる向きの先へ腕の長さ分（飛びつきは長め）ずらす。コートの外・ネットの向こうにはしない。届くかどうかなどの計算は触る点で行う
- ボールに関わる選手（受ける・トス・ブロック・フォロー）は、読む時間（能力で決まる）の後すぐ全力で動き出し、間に合えば先に着く。間に合わない時は触る時刻まで走り続ける
- スパイクの助走は、踏み切りの時刻に着く決まった長さの移動として記録する
- 備える動き：セッターは誰が1本目を触るか決まったら毎回、相手が打った時点（読む時間の後）でセットする位置へ走り出す（後衛のセッターはサーブレシーブで後ろに立ち、前へ上がる）。パスが上がったら走っている途中から落下点へ向きを変えて追い、間に合えば（最後に手を伸ばす分 `SET.setterLunge` を含む）セッターが上げる。間に合わなければ届く所まで追い、ほかの選手が二段トスを上げる。二段トスを上げる選手は、落下点に間に合う選手の中から役割の優先順位（リベロ → 後衛 → 前衛のアウトサイド・オポジット → ミドル）で選び、同じ順位なら一番近い選手。誰も間に合わなければ一番近い選手。触らない選手は相手が打った時点で助走位置へ下がり、跳んでいた選手は着地して立て直したらすぐ動く。守備の基本位置へは相手が触った時点から戻る
- セッター以外のこれらの動きは、誰が触るかを決めた後に判定上の位置を更新するので、記録で先に動き出していても、判定がその選手の元の位置を使うことはない
- 新しく決まった移動は、それより後に始まる予定だった同じ選手の移動を取り消す
- 記録の見た目の修正で結果が変わらないことは `tests/outcome.test.ts`（保存してある結果との照合）で確かめる。結果そのものを変える修正をした時は `npx tsx scripts/outcome-fixture.ts > tests/fixtures/outcomes.json` で作り直す

## スパイクのフォロー（結果に影響する）

味方がスパイクを打つ時、打たない選手はアタッカーの後ろ側の半円（`COVER.slots`）に寄る。ブロックされたボールを拾えるか・ワンタッチで戻ったボールを追えるかは、その時刻に移動の途中のどこにいるか（判定上の位置）から判定する。寄る動きを入れた分、フォローの確率 `BLOCK.coverChance` を 0.18 → 0.16 に下げ、ブロック得点の割合を元の水準（男子約11%・女子約10%）に保った。

## スパイクの助走

- 助走を始める位置：アウトサイド・オポジットはネットから4.0m（打つレーンより外側から斜めに入る）、ミドルは2.6m。触らない前衛は攻撃の準備でここへ下がる
- 始めるタイミング：オープンはトスを見て（読む時間の後）、平行はトスの少し前（`APPROACH.fastLead`）、速攻・時間差はパスの間。1本目を触った選手は触った後から
- 助走の速さはスピードで決まる（平均約3m/s、十分な助走で約1秒）。戻りきれていなければ途中から助走し（短くなる）、遠すぎれば早く動き出し、それでも足りなければ踏み切りが遅れる
- 最高の打点は身長と跳躍だけで決まる。実際に跳ぶ高さは助走の長さで下がる（助走なしで75%）。特能で高さは上げない
- 踏み切りのタイミングのずれ（判断＝テクニック、トスのずれが大きいほど増える）と遅れで、ジャンプの頂点からずれた低い所で触る。空中で合わせられないほど外れたら跳ばずにつなぎで返す
- トスのずれは、トスを見てから踏み切るまでに直せる分（スピード）を差し引き、残った分（`miss`）を攻撃力・ミスの罰にする。速攻・平行は直す時間が短く、オープンは長い
- セッターの配球の判断に、アタッカーの助走の準備（長さ・遅れ）を加えた（判断の正確さはテクニック）
- 時間差：速攻の時刻に踏み込んで止まり（フェイク）、その場でもう一度跳ぶ。打つミドルが速いほど相手が跳ばされやすい
- オープンのトスの滞空時間は、打点の3m上まで上がって落ちる物理に合わせて1.65秒

## サーブのトスと助走

- 構える → サーブトス（0.6秒）→ 助走 → 踏み切り → 打つ（`SERVE_RUN`）
- フローター：助走なし、低いトス（0.55秒）。ジャンフロ：1.5m・0.55秒の助走、トス0.95秒、跳躍の半分。スパイクサーブ：2.6m・0.8秒の助走、高いトス1.25秒、跳躍の9割。踏み切りはエンドラインの後ろ
- サーブトスのずれはテクニック（そのサーブの場面の能力なので、特能「サーブトス×」「◎」が効く）。助走の途中で直せる分はスピード
- 直しきれなかった分と踏み切りのタイミングのずれ（テクニック）で、威力が下がり、狙いがずれ、ミスが増える。空中で合わせられないほどずれたら打ち損じ
- 全体のミス率・エース率は、変更前の水準になるよう基本のミス率と威力を調整した

## レシーブの崩れと攻撃の強さ

- 崩れた所（ネットから遠い所）から上げたトスは、打つ位置もネットから離れる（`SET.offNetCarry`）。ネットから遠いほど角度のある強打を打てる範囲が狭くなる。崩れたパスからのトスの精度も大きく落ちる（`SET.errOffsetK`）
- 守る側が打球を読むまでの時間に、攻撃の速さによる遅れを足す（`ATTACK.readDelay`）。オープンはトスの間に構え直せるが、速攻・平行は読みにくい
- レシーブ・ディグ、ブロック、打つ場所を選ぶ判定は、その時刻に記録の上でいる位置（守備の位置へ動いている途中ならその途中）から行う
- 目安（同程度のチーム同士）：レシーブのずれ0.5m未満でサイドアウト率約6割、3m以上で約45%

## 1セットの進行（`match.ts`）

- 得点・サーブ権・ローテーション（サイドアウトで得点した側が回す）・セットの終わり（25点・2点差、最終セット15点）
- 停止（自チームだけ）：0・10・20点の定期停止（最終セットは0・8点、8点はコートチェンジと同時）、連続失点（点数帯は両チームの高い方。0〜9点4連続・10〜19点3連続・20点〜2連続、最終セットは0〜7点3連続・8点〜2連続。5点以上リードで1つ増やす。ちょうど達した時に止まる。定期の停止と同時なら両方の理由を出す）
- タイムアウト：1セット2回。監督特能を1つ選び（持っていなければ基本効果＝自チーム全体の能力＋1）、効果は5ラリーで切れる。方針（作戦）の変更もここで
- 監督特能（`manager.ts`。獲得・失効は第3段階）：3つまで持てる
  - タイムアウト系（5ラリー）：檄＝自チーム全体+5、立て直し＝自チームのサーブレシーブ・ディグのテクニック+10、サーブ崩し＝相手のサーブのパワー・テクニック-10、エース対策＝相手のエース1人（タイムアウトの時点の前衛で一番攻撃力の高い選手）のスパイクのパワー・テクニック-10
  - 常時系：勝負師＝最終セットの間ずっと自チーム全体+5、データ分析＝試合前・セット間の画面に相手の方針・エース・選手の傾向（緑）を出す（計算には効かない）
  - 勝負勘：止まった時に1試合1回、次の1ラリーだけ方針を変える（タイムアウトの回数は使わない）
  - 効いている間の得点率の差（男子／女子、点）：檄 +6.4／+8.5、立て直し +2.7／+3.4、サーブ崩し +1.5／+1.3、エース対策 +2.6／+4.7、勝負師 +6.4／+8.5
- 選手交代：1セット6回まで。先発はまだ出ていない控えと交代でき、入った控えは入れ替わった先発とだけ戻れる。戻った組はもう交代できない。リベロは自動
- 疲れ：ラリーの負荷 ×（1.5 − スタミナ/100）で積み上がり、ベンチでは少し回復。1ラリーの計算へは疲れとして渡す

## リベロ

- 後衛のミドルと自動で入れ替わる（サーブを打つミドルは除く）。入れ替わりは交代の回数に数えない
- サーブ・ブロック・攻撃（スパイク・フェイント・ツーアタック・ダイレクト・バックアタック）をしない
- フロントゾーン（アタックラインよりネット側）で2本目を上げる時はアンダーハンド（公式ルール：オーバーハンドで上げると、味方がネットより高い位置で攻撃できない）。精度が少し落ちる（`LIBERO.underhandErr`）。記録のトスに `underhand` を付け、描画はレシーブと同じ腕の形
- 特能「アンダートス」は二段トスの場面で効く（フロントゾーンのアンダーハンドのトスにも効く）

## 記録の体の位置（見た目。判定の位置は変えない）

- 片手で打つ時（スパイク・サーブ・ツーアタック）は、ボールが打つ腕の側の肩の上に来るよう、体を打つ腕と反対側へ `RECORD.hitSide` ずらす（利き腕は記録の並びの `hand`）
- トスは額の上の少し前で触るので、体はトスの向きと反対へ `RECORD.setBehind` 下がる。ブロックは手をネットの上へ突き出す（`RECORD.blockHandsU`）
- 攻撃を終えた側は、ボールがネットを越えた（ブロックで相手側へ行った）時点から守備の持ち場へ動き始める（`DEFENSE_RETURN`）

## 相手チームの采配（`coach.ts`）

栄冠ナインと同じく、相手は交代だけをする（spec.md「相手チームの采配」）。タイムアウト・監督特能・方針の変更はしない（相手の方針は試合を通して変わらない）。基準は `COACH`。

- 疲れた先発（疲れ0.45以上）を同じポジションの控えと替え、0.25まで回復したら戻す
- 終盤、次に自分たちがサーブする時に、サーブのうまい控えがいればピンチサーバーとして入れる
- セット間：先発は最初の形に戻す。疲れが残っている先発だけ、そのセットは控えにする
- 交代は、得点の一言の後ろと次の停止画面に出す（止まらない）

## ピンチサーバー（両チーム）

- 次にサーブするのが自分たちの時、次のサーバー（ゾーン1の先発）を控えと替えられる。サイドアウトしたら自動で先発が戻る（交代は2回分。残りが2回以上ある時だけ）
- こちらは停止画面の交代で「サーブの間だけ」を選ぶ。戻ったことは画面の一言で分かる

## 試合の進行（`game.ts`）

- 3セットマッチ（2セット先取）・5セットマッチ（3セット先取）。最後のセットが最終セット（15点）
- 試合の前とセットの間に止まり、自チームの先発と並び（2か所の入れ替え・全体を回す・控えとの入れ替え・リベロの入れ替え）と方針を変えられる。初期値は前のセットの先発と並び
- サーブ権：第1セットと最終セットは抽選、ほかは前のセットと交互
- コートチェンジ：毎セットの終わりと、最終セットの8点
- タイムアウトの効果・連続失点・タイムアウトと交代の回数はセットごとに作り直すので、次のセットに残らない
- 疲れは次のセットに持ち越し、セットの間に `FATIGUE.setBreakRecover` だけ回復する

## 選手のデータ（`types.ts` の Player、`player.ts`）

育成でセーブするデータと、試合中だけの状態を分ける。試合の計算が読むのは能力・適性・特能・調子・信頼度だけ。

- 最初に決まって変わらないもの：選手ID、名前、入学年度（学年はここから計算）、身長の伸びしろ（見えない。男子はほとんど0〜3cm、たまに5〜8cm、まれに10〜15cm、女子は×0.6）、利き腕（今は持つだけ）、見た目（髪型・髪色・肌の色の番号）
- 育成で変わるもの：背番号、6能力と能力ごとの経験の端数（1たまると能力が1上がる。全員100まで）、身長（4月の身体測定）、ポジション適性と位置ごとの経験、特能と特能のきっかけの進み具合、調子（試合中は変えない）、信頼度、怪我の残り日数、通算成績（出場試合・セット、スパイク得点、ブロック得点、サービスエース）、進路
- 枠だけ（中身は後の段階で）：性格、出身中学、主将（部員全体 Squad の captainId）
- 試合中だけ（セーブしない）：疲れ、タイムアウトなどの一時的な上下、コート上の位置と交代の状態
- ポジション適性：4段階（－・△・○・◎）。効きの割合は `APTITUDE.factor`（仮：0.6・0.75・0.9・1.0）。その位置で1セット出ると経験がたまり、`APTITUDE.expToNext` に達すると1段階上がる（練習での伸びは練習の段階で）
- 信頼度：見えない値（0〜100）。1セット出るごとに `TRUST.perSet` 上がる。試合中だけ全能力に上乗せ（40以上で+1、80以上で+3。特能と同じ段階の値）。打点・到達点の計算（身長と跳躍だけ）には入らない。画面には出さず、イベントの条件にも使わない
- 試合の後：Match が選手ごとに出たセット・位置・得点を集め（`lines`）、`applyMatch` で通算成績・信頼度・適性の経験に反映する

## ディグの乱れ

相手の攻撃を拾ったボールは、上がったボールの位置のずれに `DIG` の分を足す。足す量は、打球の強さがディグする選手の技量（レシーブと同じ。テクニック中心）を上回るほど大きい。強打は大きく、ワンタッチは中くらい、フェイントは少し。サーブレシーブとチャンスボールには足さない。目安（男子）：強打のディグの平均のずれは、サーブレシーブ（約1m）より大きい。相手の攻撃を拾ってからの攻撃の決定率は、サーブレシーブからの攻撃より 男子1ポイント・女子3ポイント低い（`scripts/flow-check.ts`）

## 判断

判断を表す能力はなく、既存の能力で正確さが決まる。

- サーブの狙い：テクニック（場面 `serveAim`）が高いほど多くの候補を比べ、レシーバーが取りにくい所を選ぶ。狙いどおり打てるかもテクニック
- 配球：セッターのテクニック（場面 `setChoice`）が高いほど、相手ブロックが薄くなりそうな攻撃を選ぶ
- ブロックの読み：ブロック能力（場面 `blockRead`）で、トスを見て動き出すまでの時間と、時間差のフェイクに跳ばされる確率が決まる
- スパイクの打ち分け：テクニックが高いほど守備のいない所を選べ、狙いのずれも小さい。ブロックの手に当てずに打て、当たってもずらして当てて止められにくい
- 軟打への切り替え：ブロックの壁が厚いのを読めるほど（テクニック）軟打でかわす
- レシーブの動き出し：打球を読んで動き出すまでの時間はテクニック、走る速さはスピードで決まる

女子はテクニックの重みが大きい（1.35）ので、軟打や打ち分けでブロックを避け、強打が減った分レシーブで拾われてラリーが続く。目安（同程度のチーム同士）：ブロック得点 男子11%・女子10%、平均打数 男子6.4・女子7.6

## 特能（`traits.ts`、spec.md「特能の数値と型」）

- 段階の付け方：場面が狭い特能は+10、場面が広いものや常に効くものは+5。赤は同じ基準でマイナス。金は元の青から1段上
- `stat`（青・赤・金・その他）：`{ 場面, 能力, 段階 }` の組を持つ。段階は ±1/3/5/10/15 だけ（`validateTrait` で確認）。計算は判定のたびに場面の一覧を作り、その場面での能力を引く
- 効く範囲（`target`）：自分だけ／`frontRow`・`backRow`（持ち主と同じ列の味方、自分を含む。号令・守備の要）／`opponent`（向き合っている相手。配球バレ：トスを上げた選手の相手ブロッカーの読みが上がる）
- 判断の場面：サーブの狙い（`serveAim`）、サーブの種類（`serveChoice`）、配球（`setChoice`）、トスを読む（`blockRead`）。弱点狙撃・配球眼・コース読みはここで上がる
- 調子の場面：`slump`（不調以下）・`goodForm`（好調以上）。安定感＝不調の時に全+3、ムラっ気＝好調で全+3・不調で全-3
- 金：元の青と置き換わる（両方持っていても金だけが効く。`hasTrait` は元の青も持っている扱い）。◎と金のサーブは◯がなくても打てる（`alsoUnlocks`）
- 5段階で表せない効き（相談して決めたもの）：全力・サボり屋＝疲れのたまり方×1.3／×0.7（`TRAIT_EXTRA`）、アウト多め・ネットにかける＝スパイクミスのうちネットの割合を0.2／0.75に寄せる、エースの風格＝持ち主が決めるとチーム全体に全+1が3ラリー（`ACE_AURA`、試合の側で扱う）
- ピンチサーバー：途中から入った選手のサーブで上がる（場面 `pinchServe`）。サーブの時だけ入れる交代は相手の采配と一緒に作る
- 連続サーブ：今のサーバーのサーブで続けて取っている間（場面 `serveStreak`。サイドアウトで取った1点は数えない）
- 打点・ブロック到達点は特能の影響を受けない（身長と跳躍だけ）
- 解禁型：特能がないとその動作自体が出ない（下の「解禁型の動作」）

### 緑（行動の傾向。`STYLE` の定数で効かせる）

目標は「平均では釣り合っていて、相手や状況によって得・損が入れ替わる」こと。確かめ方は `scripts/style-check.ts`（相手や状況を変えて、持たせない場合との得点率の差を比べる）。男女で効き方が違いすぎるものは、男女の重み（`…K`）で合わせる。

- 強気サーブ／安全サーブ：ミスの率×1.5・強さ+5／×0.55・-5。サーブの種類を選ぶ時もミスを軽く／重く見る。レシーブの強い相手には強気、弱い相手には安全が得
- ショート多め／ロング多め：狙う深さ。ショートはネットにかけやすく（ミス×1.15）、ロングは押し込む分だけ強さ+3。遅いレシーバーにはショート、速いレシーバーにはロングが得
- 人狙い／つなぎ目狙い：一番レシーブの弱そうな選手の正面／選手の間を、候補を増やして狙う。弱いレシーバーが1人いる相手には人狙いが得
- ストレート好み／クロス好み：サイドから打つ時、ストレートに打つ割合（好みなし0.4・0.7・0.15）。ストレートはアウトしやすく（ミス×1.2、女子は重み1.6）、ブロックが強いほど外の手で止められる（壁×（ブロック能力/50）^1.5、遅れたブロックには×0.7）。クロスはコートが長く入りやすい（ミス×0.88）、思い切り打てる（女子は打球の強さ×1.15）。ブロックの強い相手にはクロス、弱い相手にはストレートが得
- 強打志向／軟打志向：軟打に切り替える割合×0.65（女子は重み0.5）／×1.3。軟打志向は落とし所がうまい（狙いの候補を1つ増やす。男子は半分の割合）。守備が前寄りの相手には強打、ブロックが高い相手には軟打が得
- コミット寄り／リード寄り：時間差のフェイクに掛かる割合×1.5／×0.6、速攻への反応0.06秒早い／0.03秒遅い、サイドへの反応0.08秒遅い／0.07秒早い。速攻中心の相手にはコミット、エース中心の相手にはリードが得
- 積極守備／消極守備：届く距離+0.3m／-0.2m（女子は重み0.5）、打球の強さに比例した技量の増減（強さ1あたり-0.12／+0.12）、ばらつき×1.2／×0.8。積極は届く範囲が広いが強打を弾きやすく、消極は強打も確実に上げる（男子で強打を弾く割合 12%／1%）。強打の多い相手には消極が得
- オーバー派／アンダー派：揺れるサーブ+6・強いサーブ-6／-3・+3。ジャンフロの多い相手にはオーバー、スパイクサーブの多い相手にはアンダーが得
- エース頼み／散らし好き：エースに集める割合×1.3（上限0.9）／均等に半分寄せる
- コース読み（青）：相手アタッカーにコースの好みがあれば、そちらに寄って跳ぶ。打ったコースが当たると、触る判定の壁が×1.3
- 残っている偏り：女子のストレート好み／クロス好みは、平均でストレートが少し得（+0.7／-0.6点）。ブロックに跳ばない前衛がクロスの手前を守るので、打球の遅い女子はクロスが拾われやすいため。守備の配置と一緒に第5段階のバランス調整で見る

### 解禁型の動作

- ジャンフロ◯・スパイクサーブ◯：そのサーブを打てる（打つかはサーブの選び方で決まる）
- バックアタック（OH・OP）：後衛の時、アタックラインの後ろ（`BACK_ATTACK.minTakeoffU`）から踏み切って打つ。トスの種類 `back`。回転をかけて弧を描くので遠くからでも強打でき（`arcU`）、ネットから離れている分ブロックの手に当たりにくいが、打球は少し弱い
- ツーアタック（S）：前衛のセッターが、パスが良い時（ずれ0.8m以下）に2本目を片手で相手コートのネット際に落とす。動作 `dump`。相手はトスだと思って構えているので読むのが遅れる。正面に相手の前衛がいれば、ブロックで止められることがある
- リバウンド（OH・OP・MB）：軟打を選んだ時にブロックの壁が厚ければ、わざとブロックに当てて自分のコートに戻し、攻撃をやり直す。うまく当てられるかはテクニック。記録の形は変えず、軟打 → ブロック → 自チームが触る、の並びで表す
- ブロード（MB）：セッターの後ろへ横に走り、片足で踏み切って空中で横に流れて打つ。トスの種類 `broad`（速い攻撃として、速攻と同じ特能の場面に入る）。記録のジャンプに `oneFoot` を付ける

### スパイクのコース

サイドから打つ時（レーンの |v| が1.5以上）は、先にストレートかクロスかを決めてから狙う（場面 `attackStraight` / `attackCross`）。ストレートは打った側のサイドライン沿い、クロスは反対側に落とす。

### サーブの選び方

持っているサーブ（フローターは全員）ごとに、ミスの率とレシーバーのパスの良さの期待値を見積もり、「ミスしない × 崩せそう（サイドアウトの目安で換算）」が一番良いものを打つ。見積もりには自分の能力、相手レシーバーの得手不得手（揺れる球・強い球の場面）、男女の重みが入る。判断の正確さはテクニック（場面 `serveChoice`）で、低いほど見積もりがぶれる（`SERVE_CHOICE`）。選ぶための乱数は別に持つので、フローターしか持たない選手の結果は変わらない。

### 特能の効き方の一覧（`scripts/trait-check.ts`）

同じ能力の2チームで、自チームの「その特能が効く位置の選手」（`defaultHolders`）に1つだけ持たせ、持たせない場合と得点率を比べる。種の組を変えて平均し、ばらつきの目安も出す。同じ段階の中で極端に大きいもの・効きが見えないもの・向きが逆のものに印を付ける。エースの風格・全力・サボり屋はセットを通して比べる。直すのは特能の付きやすさ（後の段階）で、個々の数値は調整しない。
