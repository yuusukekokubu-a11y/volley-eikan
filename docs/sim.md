# 試合計算（1ラリー）メモ

`src/sim/` が試合の計算。描画は知らない。`simulateRally(input)` が1ラリーの記録 `RallyRecord` を返す。

- 型：`src/sim/types.ts`
- 調整用の数値：`src/sim/constants.ts`（試作で変える前提の値はすべてここ）
- 特能の差し込み口：`src/sim/traits.ts`（今は特能を1つも登録していない）
- 確認用：`npm run rally`（多数のラリーの集計）、`npm run rally -- 19`（種19のラリーの中身）

## 記録の形

- 座標はメートル。x は長辺方向でネットが x=0、チームAは x<0、Bは x>0。y は短辺方向、z は高さ
- `placements`：ラリー開始時の選手の位置
- `events`：時刻順。`move`（移動）、`jump`（跳ぶ）、`action`（サーブ・レシーブ・トス・スパイクなどの動作）、`land`（ボールが床に落ちた）、`point`（得点）
- `ball`：ボールの軌道の区間の列。水平は等速、高さは `z0 + (z1-z0)s + 4·bulge·s(1-s)`
- スパイクの `action` には打点（cm）、ブロックの到達点（cm）、ブロッカー、ブロックの上から打ち抜いたか、が入る
- レシーブ・ディグの `action` には「位置のずれ（m）」と「回転・勢い（0〜1）」が入る
- `load`：選手ごとの負荷（跳んだ回数・動いた距離など）。疲れへの換算は試合側（次の段階）で行う

## 仕様にない部分で決めたこと（現実のバレーに合わせた）

- 能力：身長は cm、ほかは 0〜100。ポジション適性も 0〜100
- 打点＝身長×1.33（指高）＋跳躍から決まる跳び上がり（45〜100cm）。ブロックの到達点は跳び上がりの78%
- ネットの高さ：高校男子2.40m、高校女子2.20m
- 並びは 5-1 を想定。リベロは後衛のミドルと自動で入れ替わる（サーブを打つミドルは除く）
- サーブレシーブはリベロとアウトサイドを中心に3人。セッターは受けない
- トスの種類：速攻・時間差・平行・オープン。ずれが小さい時だけ速いトスを使える。セッターが1本目を触った時や、ずれが大きい時は、ほかの選手が二段トス（オープンのみ）
- 打てないトスはつなぎで返す（相手のチャンスボール）。ずれが大きすぎるレシーブは相手コートへ返ってしまうことがある
- スパイクの結果：ミス（ネット・アウト）／フェイント・軟打／ブロックのシャット・ブロックアウト・ワンタッチ／抜けた強打
- ブロックは「反応→横移動→踏み切り」がトスの滞空時間に間に合うかで枚数と間に合い具合が決まる。時間差ではミドルがフェイクに跳ぶことがある
- 守備は「ボールが来るまでに走れる距離＋飛びつき」で届くかを判定。跳んだ選手は着地してすぐは動けない
- シャットされたボールを味方が拾う（フォロー）ことがある
- 打ち分け：テクニックが高いほど守備のいない所を選べ、狙いのずれも小さい。低い打点だとネットを越えるために深くしか打てない
- 男女の重み：体の能力（跳躍・パワー・スピード、ブロック）が攻撃力・サーブの威力・ブロックの強さに効く量に「体の重み」、テクニックに「技の重み」、作戦が合った時の補正に「作戦の重み」を掛ける。移動の速さそのものには掛けない

## 特能との関係（今は未実装）

- バックアタック、ブロード、ツーアタック、ダイレクト、パンケーキなど「その特能がないとできない動作」は、特能がない状態では出ない
- 速攻・時間差・フェイント・ワンタッチ・ブロックアウトは基本の動作として出る。特能はその成功率などを上げる形で足す
