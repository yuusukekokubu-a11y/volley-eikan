# 高校バレー監督ゲーム 仕様書

最新版は Claude Docs の仕様書。このファイルは 2026-11-18 時点の写し。
「案」と書かれた部分や数値は、試作で調整する前提。

## 概要

栄冠ナインをベースに、高校バレー部の監督として部員を育て、全国大会を目指すゲーム。バレーに合わない部分だけ置き換える。

- 男子・女子を選べる（戦術の違いが出る）
- 目標大会：インターハイ（夏）、春高（1月）
- 実装はAI（Claude Code）に任せる前提。規模はAIで作れる範囲に収める
- プラットフォーム：中身は1つのWebアプリ。PCはブラウザで、スマホは同じものを簡易的にアプリ化する
- 画面は横持ち固定で、PCとスマホ共通。操作はタップ前提（ホバーで情報を出さない）。スマホの横持ちは高さが狭いので、表の多い画面はスクロールやタブで工夫する

## 進行と育成

進行は栄冠ナインと同じ双六形式。

- 進行カード（アイコン）の数字の日数分だけパネルを進む（1マス＝1日）
- パネルの種類と効果は栄冠ナインに準じる（青・赤・白・緑・黄、特訓、ルート分岐など）
- 新入生の仕組みは栄冠ナインと同じ
- スカウトは最初の版には入れず、ある程度遊べる形になってからアップデートで追加する
- 年間の山場：インターハイ予選・本戦、春高予選・本戦。3月卒業、4月入学
- 3年生は春高（1月）の後に引退し、3月に卒業する。引退から卒業までは試合にも練習にも出ない（2年生中心の新チームの期間）

### 練習の仕組み

- 2層：選手ごとの練習指示（どの能力を伸ばすか）＋進行カードの練習の種類
- 身長以外の6能力それぞれに、機材なし・下位機材・上位機材の3種類＋総合系2種類、計20種類

| 能力 | 機材なし | 下位機材 | 上位機材 |
| --- | --- | --- | --- |
| 跳躍 | バウンディング | ジャンプボックス | ジャンプ測定器 |
| パワー | 体幹・自重トレ | ダンベル | バーベル・ウェイトマシン |
| スピード | ダッシュ | ラダー | 反応トレーニング機器 |
| テクニック | 対人パス | トス練習リング | ボールマシン |
| ブロック | シャドーブロック | ブロック練習台 | スパイクマシン |
| スタミナ | 走り込み | エアロバイク | 低酸素トレーニング機器 |

総合系（機材なし）：総合練習（全体に少しずつ）、紅白戦（全体に少しずつ＋特能のきっかけなど試合形式ならではの効果）

高効率カード（本家の特打・特守にあたる）。チーム方針と機材の組み合わせで出る。方針と一対一でなくてよく、数や条件は後から増やせる。

| カード | 出る条件（案） | 伸びる能力 |
| --- | --- | --- |
| 打ち込み | 攻撃重視＋ダンベルかバーベル＋ジャンプボックスかジャンプ測定器 | パワー大、跳躍大 |
| 千本レシーブ | 守備重視＋トス練習リングかボールマシン | テクニック大、スピード大 |

「特訓」の名前は、後で作る特能イベント（本家の特訓パネルにあたるもの）のために空けておく。

### チーム方針

効き方は本家と同じ（方針で出やすい進行カードが変わる、高効率カードの条件になる）。

| 方針 | 伸びやすい能力 |
| --- | --- |
| 総合 | 全体 |
| 攻撃重視 | パワー、跳躍 |
| 守備重視 | テクニック、ブロック |
| スピード重視 | スピード、テクニック |
| 体力重視 | スタミナ |

### 設備・機材・パネル

- 設備：本家のグラウンドレベルと同じ仕組みで、名前を「体育館レベル」にする
- 上位機材：値段が高いだけ（評判による制限はなし）
- 機材を買うと体育館レベルが上がる（上位機材ほど多く上がる）。体育館レベルが高いほど、すべての練習の経験が増える。機材そのものの倍率は持たない。機材は壊れない
- 機材を持つと、その機材を使う練習のカードが手札に出る
- お金：通貨はお金1つ。稼ぎ方は、年度の初めの部費（評判で決まる）と、試合の勝利の報奨（練習試合・大会。大会は勝ち進むほど多い）。機材は買い物の画面でいつでも買える
- 練習指示：選手ごとに、伸ばす能力（おまかせか6能力のどれか）と練習するポジションを持つ。変えられるのは本家と同じく毎月1日（通り過ぎても止まって変更画面を出す）と、まれに来る練習指示カードを使った時
- 試合でも経験が入る（本家と同じ）。練習指示の能力に入り、スタメン＞途中出場＞ベンチ入り＞ベンチ外の順に多い。作るのは第3段階の大会の時
- 調子：育成の日々の中で少しずつ上下する。安定感は変わりにくく、ムラっ気は変わりやすい
- パネル：本家と同じ（合宿、練習試合など）。体育館の取り合いは入れない（不快なだけになりそうなため）
- パネルの色：本家と同じ。青＝いいイベント、赤＝悪いイベント、白＝ランダムなイベント、緑＝体力の回復、黄＝練習の進行カードで止まると経験値が増える。ほかに特訓、ルート分岐、定期イベントのパネル
- 進行カード：手札5枚、進む日数は1〜5

### 育成用の体力

- 本家と同じく、育成中の体力を持つ。練習で減り、緑パネルや休みで回復する。体力が低いほど練習の伸びが落ちる。プレイヤーが過度に意識しなくてよい程度にする
- 合宿：本家と同じく夏と冬の年2回。1ヶ月前に開催するかを選ぶ。体力は多く減るが経験が多く入り、練習の種類に応じて特能が取れる
- 練習試合：本家と同じく、マネージャーが組む形（決まった時期に起きる）
- 入学式・卒業式・身体測定：結果を出すだけで、文章や選択肢のあるイベントにはしない
- 怪我：練習できなくなる「怪我の状態」はない（本家と同じ）。怪我はイベントの効果の1つで、能力・体力・調子が少し下がるだけ。体力が低いと、そのイベントで怪我をしやすい程度
- 試合中の疲れ（ゲージを見せず内部で処理するもの）とは別のもの

## 選手の能力

基本能力は7つに絞り、細かい個性はポジション適性と特殊能力で表す（能力値を増やしすぎない）。

| 区分 | 項目 |
| --- | --- |
| 基本能力 | 身長、跳躍、パワー、スピード、テクニック、ブロック、スタミナ |
| ポジション適性 | セッター、アウトサイド、ミドル、オポジット、リベロ |
| 特殊能力 | 青（プラス）・赤（マイナス）・緑（スタイル）・金（青の上位） |

- テクニック：トス、レシーブ、打ち分け、フェイントなど「ボールを思い通りに扱う上手さ」。何に効くかはポジション適性で変わる（例：セッター適性が高いとテクニックがトスの上手さになる）。レシーブの得手不得手などの個性は特殊能力で表す
- 打点の高さは身長と跳躍だけから決める。高さを上げる特能は作らない（どこで高さを稼いでいるかの納得感のため）

### スタミナの効き方

- 試合が長引くほど（セット数・ラリー数・打数が増えるほど）能力が少しずつ下がり、スタミナが高いほど下がり方が小さい
- 試合中の疲労はゲージとして見せず、内部で処理する（情報量を増やさないため）
- 例：エース中心だとエースの打数が増えて終盤にバテやすい

### 身長の伸び方

- 練習とは無関係。入部時に選手ごとの見えない「伸びしろ」が決まる
- 伸びるのは主に1・2年生の間
- 男子の伸び幅：ほとんどの選手は0〜3cm、たまに5〜8cm、まれに10〜15cm。女子は全体的に小さめ
- 毎年4月の身体測定イベントでまとめて更新する
- 伸びしろは見せない。寸評やイベントで「まだ伸びそう」とほのめかす程度

### 特殊能力の方針

- 緑＝スタイル（良し悪しではない）、青＝能力が直接上がるもの
- 組み合わせのシナジーは意図して作り込まない（「この組み合わせなら効果アップ」という表を作らない）。現実ベースの仕組みから、噛み合ったら強いという形が自然に生まれるのが理想
- 現実的に噛み合っていないのに強い組み合わせが出たら、相談して調整する
- 調子：本家と同様に選手の調子（好調・不調）がある
- 選手が特能を覚える方法：本家と同じ（特訓パネル、合宿、試合、本など）
- サーブ：普通のフローターは誰でも打てる。ジャンフロとスパイクサーブは特能（◯）で解禁する。狙いの正確さはテクニックで決まり、青特能「弱点狙撃」は狙いを決める時だけテクニックが上がる

### 特能の数値と型

- 青・赤・金の効果は、すべて「どの場面で・どの能力が・何段階上下するか」の形で書く。確率や距離を直接いじる特能も、その場面での能力値の上下に置き換える
- 上下する値は固定の5段階：+1、+3、+5、+10、+15（赤は同じ段階のマイナス）。説明文では数字を出さず、「わずかに」「少し」などの言葉で表す
- 個別の特能の数値は調整しない。バランスがおかしい時は、能力全体のプレーへの効き方と、特能の付きやすさで調整する
- 緑（スタイル）は数値の上下ではなく行動の傾向を変えるものなので、この5段階の対象外
- 段階の付け方の基準：場面が狭い特能は+10、場面が広いものや常に効くものは+5（赤は同じ基準でマイナス）。金は元の青から1段上
- 解禁型：特能がないとその動作自体が出ないもの（バックアタック、ブロード、ツーアタック、ジャンフロ◯、スパイクサーブ◯）。◎はその動作が得意な特能で、金の魔球・大砲サーブは◎の上位版
- 判断：判断を表す能力は作らない。判断は全員がしていて、その正確さは既存の能力が決める（ボールに関わる判断はテクニック、ブロックの読みはブロック能力）。判断ミスは「その能力が低い結果」として自然に起きる（パワプロのエラーが捕球由来なのと同じ考え方）
- 判断を良くする特能（弱点狙撃、配球眼、コース読み、司令塔）は、「その判断をする時だけ能力が上がる」形にする
- 案：安定感＝不調の時の能力低下を打ち消す、ソフトレシーブ＝レシーブの時テクニックが上がる（勢いが死ぬのは計算に任せる）、連続サーブ＝連続得点中は固定値で上がる
- 緑「積極守備」「消極守備」が隣同士にいる時にお見合いが少し増える、のような形が自然に出たら嬉しい。ただしわざわざ実装はしない
- 試合計算の細部（打点の式、ネットの高さ、トスの種類など）は docs/sim.md にまとまっている

### 特殊能力一覧

緑（スタイル）

- サーブ：強気サーブ（攻めるがミスも多い）／安全サーブ（確実に入れる）、ショート多め／ロング多め、人狙い／つなぎ目狙い（サーブの狙い方のクセ）
- 攻撃：ストレート好み／クロス好み（打つコースの偏り。決まりやすさは変わらない）、強打志向／軟打志向
- ブロック：コミット寄り／リード寄り
- 守備：積極守備（拾える範囲が広いが弾くミスも増える）／消極守備（範囲は狭いが確実に上げる）、オーバー派／アンダー派（サーブレシーブの取り方。オーバー派は揺れるサーブに強く、強いサーブに弱い）
- トス：エース頼み／散らし好き（セッターの配球のクセ）

青（どのポジションでも持てる。効くかはポジション次第）

- 全プレー：勝負強い（セット終盤で補正。「プレッシャーに弱い」の逆）、安定感（調子の波が小さい。「ムラっ気」の逆。名前は仮）
- サーブ：弱点狙撃（レシーブの弱い選手を狙う。ない選手は狙いを定めない）、ピンチサーバー、ジャンフロ◯／スパイクサーブ◯（そのサーブを使えるようになる。解禁型）、ジャンフロ◎／スパイクサーブ◎（そのサーブが得意）、連続サーブ（連続得点中は補正。案）
- 攻撃：ストレート◯／クロス◯（対象コースに打つ時にパワー・テクニックに補正）、フェイント、バックアタック、ブロックアウト、リバウンド、二段打ち、ダイレクト（ネット際に来た相手の返球を直接打ち込む）
- ブロック：コース読み（予測が当たる。相手アタッカーのコースの好みも自動で読む）、反応（速いトスに間に合う）、ワンタッチ、キルブロック、ブロックフォロー（自分のブロックに当たって落ちたボールを拾いやすい）
- レシーブ：フェイント拾い（軟打やフェイントを拾う）、サーブレシーブ職人、ディグ（スパイクを拾う）、パンケーキ◯（床に落ちる寸前のボールを拾える）、揺れ球◯（揺れるボールでも正確に返せる）、ソフトレシーブ（勢いを殺して柔らかく返す。セッターが扱いやすい。名前は仮）
- トス：二段トス◯（崩れた時にセッター以外が上げるトスが正確）

青（ポジション専用）

- セッター：トス回し、コンビ◯（速攻や時間差のトスのタイミングが正確）、ツーアタック、配球眼（相手ブロックの薄い所に上げる）、バックトス◯、乱れ玉セット（変な所に飛んだパスでも安定してトスを上げる）、ハンドリング◯（回転や勢いが残ったボールでも正確にトスを上げる）
- ミドル：速攻、ブロード（移動攻撃）、時間差（時間差の成功率が上がる）、号令（自分がブロックに参加している時、前衛全体のブロックが上がる）
- リベロ：アンダートス、守備の要（自分が後衛にいる時、後衛全体のレシーブが上がる）

赤

- 全般：プレッシャーに弱い、ムラっ気
- サーブ：サーブミス、サーブトス×（ジャンフロ・スパイクサーブが苦手）
- 攻撃：悪球打ち×（崩れたトスだと極端に決まらない）、アウト多め、ネットにかける、速いトス×（速攻や時間差のテンポについていけない）、連続トス×（続けて自分にトスが上がると精度が落ちる）、フェイント見え見え
- ブロック：吸い込まれ（ネットとブロックの間に落とされる）、ブロックアウトされやすい（手の向きが甘く外に出される）
- レシーブ：レシーブ苦手（全般）、サーブレシーブ×（サーブカットだけ苦手）、強打レシーブ×（強いスパイクやスパイクサーブに弾かれやすい）、揺れ球×（ジャンフロやフローターが苦手）
- トス：配球バレ（トスの方向を読まれやすく、相手ブロックが揃いやすい）、バックトス×（後ろへのトスが苦手）、乱れ玉×（セッター専用。位置の悪いパスからのトスが乱れる）、ハンドリング×（セッター専用。回転や勢いが残ったボールだとトスが乱れる）

その他

- 能力の偏りを作る特能：力任せ（テクニックが下がりパワーが上がる）、技巧派（パワーが下がりテクニックが上がる）
- スタミナ（どちらも良し悪しのある特能）：全力（スタミナ消費が増えるが、全能力がわずかに上がる：+1）、サボり屋（スタミナ消費が減るが、全能力がわずかに下がる：-1）
- 削除したもの：打ち分け、ブロックの壁、ジャンプサーブ、タフ、スタミナ不足、ネットタッチ、単調サーブ、高打点、拾い屋、お見合い

実装メモ

- レシーブで上がったボールは「位置のずれ」と「回転・勢い」の2つの値を持つ。乱れ玉系は位置のずれ、ハンドリング系とソフトレシーブは回転・勢いに効く
- 時間差の条件：レシーブがセッターの近くにきれいに返った時（位置のずれが小さい時）だけ使える。使う頻度は作戦の攻撃方針で決まる。相手ブロッカーが緑「コミット寄り」だとフェイクに引っかかりやすく、「リード寄り」だと引っかかりにくい

## 男女の違い

男女は対戦しないため、能力値を一律に下げるのではなく、試合計算での効き方の重みで差をつける。

- 男子：身体能力（跳躍、パワーなど）の効き方が強い。身体能力で押し切れる
- 女子：身体能力の効き方を弱め、テクニック・レシーブ・作戦の効き方を強める。作戦がハマるとラリーを取れる

## 試合の見せ方

テキストベースは避ける。

- 試合の計算と描画を分ける
- 計算側は「誰が・どこで・どんな動作をして、ボールがどこからどこへ飛んだか」を座標付きで記録し、描画側はそれを再生するだけにする
- 計算側で打点の高さとブロックの到達点を数値で出しておく
- これにより、2Dか3Dかなど描画だけ差し替えられる

### 見せ方の段階（試合ごとに切り替えられる）

- フル：全ラリーを再生。速度は1倍・2倍・4倍
- ハイライト：普段は得点の結果だけを流し、見せ場だけ再生
- 結果のみ：停止する場面だけ止まり、ほかは一気に進む

ハイライトで再生する見せ場：セット終盤（20点以降、最終セットは10点以降）、長いラリー、ブロックの上から打ち抜いた時、停止の直前のラリー。

特能の演出は特に作り込まず、栄冠ナインと同じ程度にする。

### 角度と描き方

- ラリーを見せる角度：コートを横に置き、テレビ中継を参考に斜め上から見る。ボールの影と高さを分けて描き、高さとコース・配置の両方を伝える。スパイクの瞬間のカメラ演出やカットインは作らない（今の描画で迫力は十分と判断）
- 3Dにこだわる理由：身長と跳躍が一定を超えると「ブロックの上から打つ」が起きる。その高さを迫力をつけて見せたい。他の表現で伝わるなら2Dでも十分
- 選手の描き方：手足が浮いたデフォルメ体型に決定（肘付きの人形と見比べて選んだ）。腕と脚はなく、頭は大きめ、体は丸みのある形。手はボールに触る点へ直接置き、しゃがみは体を沈める、ジャンプは空中で靴を引き寄せるなどで表す。身長差は体の大きさで見せる。特定の既存キャラクターには似せず、顔立ちや配色はオリジナルにする
- 再生の速さ：現実の速さより少しゆっくり見せる（描画側だけで調整し、試合の計算は変えない）。どれくらい遅くするかは試作で決める
- 描画は簡易3D（Three.js）に決定。2D版は作らない

### 試合画面の表示（コートを大きく見せるため絞る）

- 常に表示：スコアとセットカウント、タイムアウトの残り回数（両チーム）、見せ方の段階と再生速度の切り替え
- コート上の人形に背番号
- 得点の結果は「〇〇のスパイク」程度の短い一言を画面の端に少しだけ出す
- 停止した時は専用の画面に切り替える

### 停止画面

- 左：スコア、止まった理由（「10点の区切り」「3連続失点」など）、タイムアウトの残り回数、ローテーションの小さな図
- 右：コート上の6人と控えの一覧（背番号、ポジション、調子、主な特能）。スタミナは数値を出さず、疲れている選手に「足が止まってきた」程度の一言
- 下：選択肢。タイムアウト（→監督特能を1つ選ぶ→方針を変える）、選手交代（→入れ替える2人を選ぶ）、何もしない（→試合に戻る）

### 試合前画面（試作：docs/mockups/pregame.dc.html）

- 左：コート図。スタート時の並び（ローテーション）を表示し、タップで入れ替える
- 右：タブで切り替え。スタメン（コート・リベロ・控えの一覧、控えとの交代）、作戦（3項目）、相手（評判と主な選手。監督特能「データ分析」があれば傾向も）
- 下：見せ方の段階と試合開始
- スタメン・並び・作戦は前回の設定を引き継ぐ

## 試合の采配

試合は基本的に見守り、決まったタイミングで止まって判断する。

### 停止のタイミング

- 定期：0・10・20点（25点のセット）。区切りが10点・10点・残り5点になり、終盤ほど判断の機会が詰まる。最終セット（15点）は0・8点（8点はコートチェンジと同時）
- 連続失点：点数が進むほど少ない連続失点で止まる

### 停止時にできること

- タイムアウトを取る
- 選手交代
- 何もしない

方針変更（作戦の変更）はタイムアウト中かセット間のみ。

### 停止とタイムアウトは別物

- 停止：監督が判断するためにゲームが止まるもの。試合の中の出来事ではない
- タイムアウト：試合の中で取る行動で、効果がある
- 停止はタイムアウトの残り回数と関係なく条件どおり起きる。使い切っていたら「タイムアウトを取る」が選べないだけ
- 定期停止の直後でも、連続失点の条件を満たしたらまた止める

### 連続失点での停止（仮決め。数値は試作で調整）

- 点数帯は両チームの高い方で判断する
- 自チームが5点以上リードしている時は、止まる連続失点を1つ増やす

| 点数帯 | 止まる連続失点 |
| --- | --- |
| 0〜9点 | 4連続 |
| 10〜19点 | 3連続 |
| 20点〜 | 2連続 |
| 最終セット 0〜7点 | 3連続 |
| 最終セット 8点〜 | 2連続 |

停止時に1本だけ方針を変える「その場限りの指示」は入れない（方針変更はタイムアウト中とセット間だけ、というルールを崩さないため）。入れるなら監督特能として。

### 選手交代のルール（実際のバレーと同じ）

- 交代は1セット6回まで
- 一度下がった選手は、自分と入れ替わった選手とだけ交代して戻れる
- 画面では、交代できない組み合わせは最初から選べないようにする
- リベロの出入りは回数に数えず、自動（ミドルが後衛に下がったら入る、など）

## 作戦

作戦は攻撃・ブロック・レシーブの3項目。試合前に決め、タイムアウト中・セット間に変更できる。指示は選手を名指しせず「方針」の形にする。

作戦の効き方

- 主は自チーム適性型：自分の選手の能力に合った作戦を選ぶと有利になる
- 相手の能力も少し影響する（読み合いではなく、見えている数値への対応）
- 自チームの調子や交代で、試合中に方針を変える理由が生まれる

作戦項目（「活きる能力」の列は案）

| 項目 | 選択肢 | 内容 | 活きる能力 |
| --- | --- | --- | --- |
| 攻撃 | エース中心 | エースに高いトスを集める。相手のブロックが高いと止められやすい | エースの身長・跳躍・パワー |
| 攻撃 | バランス | エースと速攻を混ぜる。崩れにくいが尖った強さはない | 能力が揃っていること |
| 攻撃 | 速攻中心 | ミドルの速攻・時間差を多用。能力が低いとミスが増える | セッターのテクニック、ミドルのスピード |
| ブロック | バンチ | 中央に寄る。速攻に強く、サイドへの速いトスに遅れやすい | スピード |
| ブロック | スプレッド | 広がる。サイドに確実に1枚つくが、中央の速攻に弱い | 個々のブロック |
| ブロック | デディケート | 相手エースの側に寄る。反対側が手薄 | 身長・跳躍 |
| レシーブ | 前寄り | フェイント警戒 | テクニック・スピード |
| レシーブ | 後ろ寄り | 強打警戒 | テクニック・スピード |

### 相手チームの采配

栄冠ナインと同じく、相手は交代だけをする（疲れた選手の交代、ピンチサーバー）。タイムアウト・監督特能・方針の変更はしない。試合の流れはプレイヤーの采配が中心で、タイムアウトと監督特能は「自分の武器」とする。相手の方針は試合を通して変わらない。

### 作戦の目標

相手に合わせて方針を変えることが、状況によってはちゃんと得になること。自分に合った方針を捨てる損と、相手への対策の得が比べられる形にする。

サーブと、ブロックの跳ぶタイミング（リード／コミット）は作戦に入れず、選手の個性（特殊能力）で表す。ブロックのコース（クロス／ストレート）は判断材料がないため削除。

## タイムアウトと監督特能

タイムアウトは停止と区別し、監督特能による具体的なバフ・デバフを発動する場にする。監督特能は、選手が入れ替わって戦力が落ちる年でも評判を安定させる役割も持つ。

### タイムアウト

- 1セット2回
- 取った時に、持っている監督特能から1つ選んで発動する
- 効果は相手のステータスデバフ、自チームのバフ
- 方針変更もタイムアウト中に行う
- 効果は次の5ラリーで切れる（数値は試作で調整）
- 監督特能を持っていない場合は、自チーム全体を少しだけアップする基本効果のみ

### 監督特能

- 双六のイベントなどで獲得する（獲得は難しめ）
- 最大3つまで持てる
- 取ってから数年で失効する（3年。選手が一回り入れ替わる期間）
- 同じ特能を取り直すと期限が延びる
- 3つ持っている時に新しく取れたら、入れ替えるか見送るかを選ぶ
- 獲得の場：研修会パネル、OBパネル（卒業生から教わる）、他校監督イベント（練習試合の後など）、大会の実績
- 失効の理由づけ：戦術の流行が変わる、相手校に研究される
- 学校の評判が高いほど獲得の機会が増える（名門になると獲得が緩和される）
- 評判は成績で上下する（栄冠ナインと同様）
- 名門を引きずり下ろす仕組みは入れない。名門になった後の緊張感は全体の難易度で作る（名門の手前に留まる方が得、という抜け道を作らないため）
- 細かい数値は後から調整する前提。監督特能の数は、取得確率次第で今の7つより減らすこともある

監督特能の例（案）

- タイムアウト系：サーブ崩し（相手サーバー弱体化）、エース対策（相手エースのスパイク弱体化）、立て直し（自チームのレシーブアップ）、檄（自チーム全体アップ）
- 常時系：データ分析（試合前に相手の傾向がわかる）、勝負師（最終セットで自チーム強化）
- 勝負勘：停止時に1試合1回、次の1ラリーだけ方針を変えられる
