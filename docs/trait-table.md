# 特能の効き方の一覧（確認用）

`npx tsx scripts/trait-check.ts 4000 both all 4` の結果（2026-11-19）。勝負強い・千両役者・プレッシャーに弱い・配球バレは、確かめ方を直した後に測り直した値。

- 同じ能力（平均55）の2チームで、自チームの「その特能が効く位置の選手」全員に1つだけ持たせ、持たせない場合と比べた
- 得点率の差：1ラリーで点を取る割合の差（点＝%ポイント）。±はばらつきの目安
- セット勝率の差：得点率の差を、25点のセットを取る確率に直したもの
- 判定：同じ段階の中で極端に大きい／効きが見えない（ばらつきより小さい）／向きが逆
- 直すのは後の段階（能力全体の効き方と特能の付きやすさ）。個々の数値は調整しない
